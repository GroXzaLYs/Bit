ID: PHP adalah bahasa skrip sisi-server yang dirancang untuk pengembangan web. Potongan kode berikut mendemonstrasikan fungsi sederhana untuk menghitung jumlah dari sebuah array. Perulangan 'foreach' mengiterasi setiap elemen, menambahkannya ke variabel '$sum'.
JA: PHPは、Web開発用に設計されたサーバーサイドスクリプト言語です。以下のコードスニペットは、配列の合計を計算する単純な関数を示しています。'foreach'ループは各要素を反復処理し、'$sum'変数に追加します。

[PROGRAMMING - PHP EXAMPLE]
<?php
function calculateSum(array $numbers): int {
    $sum = 0;
    foreach ($numbers as $number) {
        $sum += $number;
    }
    return $sum;
}
echo calculateSum([1, 2, 3, 4, 5]); // Output: 15
?>

[CODE - PHP OOP EXAMPLE]
<?php

    public $name;
    public function __construct($name) {
        $this->name = $name;
    }

    }
}

?>

EN: Interacting with databases is a core feature of PHP. Using PDO (PHP Data Objects), you can safely execute SQL queries, which prevents SQL injection attacks.

JA: データベースとの対話は、PHPのコア機能です。PDO（PHP Data Objects）を使用すると、SQLクエリを安全に実行でき、SQLインジェクション攻撃を防ぐことができます。

[CODE - PHP DATABASE EXAMPLE]
<?php
// Example of a secure database connection and query using PDO
try {
    $pdo = new PDO('mysql:host=localhost;dbname=test', 'username', 'password');
    $stmt = $pdo->prepare('SELECT * FROM users WHERE id = :id');
    $stmt->execute(['id' => 1]);
    $user = $stmt->fetch();
} catch (PDOException $e) {
    echo "Connection failed: " . $e->getMessage();
}
?>
